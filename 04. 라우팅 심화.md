# 1. Outlet이란? 중첩 라우팅 준비

<details>
  <summary>(1) 문제 상황: 레이아웃이 매 페이지마다 반복됨</summary>

  ```JSX
  // X 이렇게 하면 레이아웃 코드가 매 페이지마다 중복됨
  function Products() {
    return (
      <div>
        <Header />  {/* 중복 */}
        <Sidebar /> {/* 중복 */}
        <h1>상품 목록</h1>
      </div>
    )
  }

  function MyPage() {
    return (
      <div>
        <Header />  {/* 중복 */}
        <Sidebar /> {/* 중복 */}
        <h1>마이페이지</h1>
      </div>
    )
  }
  ```
</details>

<details>
  <summary>(2) Outlet으로 해결</summary>

  * `<Outlet />`은 **자식 페이지가 여기에 들어온다**는 표시
  * 공통 레이아웃은 부모 컴포넌트에 한 번만 쓰고,
  * 바뀌는 내용만 `<Outlet />` 자리에 들어옴

  ```JSX
  // layouts/MainLayout.jsx
  import { Outlet } from 'react-router-dom'
  import Header from '../components/Header'
  import Sidebar from '../components/Sidebar'

  function MainLayout() {
    return (
      <div>
        <Header />      {/* 모든 페이지 공통 헤더 */}
        <Sidebar />     {/* 모든 페이지 공통 사이드바 */}
        <Outlet />      {/* 자식 페이지 내용이 여기 들어옴 */}
      </div>
    )
  }

  export default MainLayout
  ```
</details>

# 2. 중첩 라우팅(Nested Routes)
<details>
  <summary>(1) 중첩 라우팅 기본 구조</summary>

  ```JSX
  // App.jsx
  import { Routes, Route } from 'react-router-dom'
  import MainLayout from './layouts/MainLayout'
  import Home from './pages/Home'
  import Products from './pages/Products'
  import MyPage from './pages/MyPage'

  function App() {
    return (
      <Routes>
        {/* MainLayout이 부모 Route */}
        <Route element={<MainLayout />}>

          {/* 자식 Route들 - Outlet 자리에 들어옴 */}
          <Route path="/"            element={<Home />} />
          <Route path="/products"    element={<Products />} />
          <Route path="/mypage"      element={<MyPage />} />
        </Route>
      </Routes>
    )
  }
  ```

  * 부모 `<Route>`에 `path`가 없고 `element`만 있으면 URL과 관계없이 항상 렌더링되는 레이아웃임
</details>

<details>
  <summary>(2) 2단계 중첩: 마이페이지 하위 메뉴</summary>

  ```txt
  /mypage             -> 마이페이지 기본 화면
  /mypage/orders      -> 주문 목록
  /mypage/wishlist    -> 찜 목록
  ```
  ```JSX
  // pages/MyPage.jsx - 마이페이지 자체도 레이아웃 역할
  import { Outlet, NavLink } from 'react-router-dom'

  function MyPage() {
    return (
      <div>
        <h1>마이페이지</h1>
        <nav>
          <NavLink to="/mypage/orders">주문 목록</NavLink>
          <NavLink to="/mypage/wishlist">찜 목록</NavLink>
        </nav>
        <Outlet />  {/* 하위 페이지가 여기에 들어옴 */}
      </div>
    )
  }

  export default MyPage
  ```
  ```JSX
  // App.jsx - 2단계 중첩
  function App() {
    return (
      <Routes>
        <Route element={<MainLayout />}>
          <Route path="/"          element={<Home />} />
          <Route path="/products"  element={<Products />} />

          {/* MyPage 하위에 또 중첩 */}
          <Route path="/mypage"      element={<MyPage />}>
            <Route path="orders"        element={<Orders />} />
            <Route path="wishlist"      element={<Wishlist />} />
          </Route>

        </Route>
      </Routes>
    )
  }
  ```

  * 자식 Route의 `path`는 부모 path를 자동으로 이어받음
  * `path="order"` -> 실제 URL은 `/mypage/orders`
</details>

<details>
  <summary>(3) index Route: 기본 자식 페이지</summary>

  `/mypage`에 접속했을 때 `<Outlet />` 자리에 보여줄 기본 페이지를 지정
  ```JSX
  <Route path="/mypage" element={<MyPage />}>
    <Route index element={<MyPageMain />} />    {/* /mypage 기본 페이지 */}
    <Route path="orders"        element={<Orders />} />
    <Route path="wishlist"      element={<Wishlist />} />
  </Route>
  ```
</details>

# 3. useParams로 동적 라우팅: 상품 상세페이지 만들기

<details>
  <summary>(1) 동적 라우팅이 필요한 이유</summary>

  ```JSX
  // X
  <Route path="/products/1"  element={<Product1 />} />
  <Route path="/products/2"  element={<Product2 />} />
  <Route path="/products/3"  element={<Product3 />} />
  // ... 100개?? 10000개??
  ```
  ```JSX
  // O, 동적 라우팅으로 한 줄로 해결
  <Route path="/products/:id"  element={<ProductDetail />} />

  // :id 자리에 어떤 값이 와도 ProductDetail 컴포넌트를 보여줌
  ```
  * `:id`에서 `:`는 "이 자리는 변할 수 있다"는 표시임
</details>

<details>
  <summary>(2) useParams로 URL 값 읽기</summary>

  ```JSX
  // pages/ProductDetail.jsx
  import { useParams } from 'react-router-dom'

  function ProductDetail() {
    const { id } = useParams()  // URL의 :id 값을 가져옴

    return (
      <div>
        <h1>{id}번 상품 상세페이지</h1>
      </div>
    )
  }

  export default ProductDetail
  ```
  ```JSX
  // App.jsx
  <Route path="/products/:id"  element={<ProductDetail />} />
  ```
</details>

<details>
  <summary>(3) 실전 예시: 상품 목록 -> 상세페이지</summary>

  ```JSX
  // pages/Products.jsx - 삼품 목록
  import { Link } from 'react-router-dom'

  const productList = [
    { id: 1, name: '맥북 프로' },
    { id: 2, name: '아이폰 15' },
    { id: 3, name: '에어팟 프로' },
  ]

  function Products() {
    return (
      <div>
        <h1>상품 등록</h1>
        {productList.map((product) => (
          <div key={product.id}>
            <Link to={`/prodcts/${product.id}`}>
              {product.name}
            </Link>
          </div>
        ))}
      </div>
    )
  }

  export default Products
  ```
  ```JSX
  // pages/ProductDetail.jsx - 상품 상세
  import { useParams, useNavigate } from 'react-router-dom'

  const productList = [
    { id: 1, name: '맥북 프로', price: '3,490,000원', desc: '강력한 성능의 노트북' },
    { id: 2, name: '아이폰 15', price: '1,250,000원', desc: '최신 스마트폰' },
    { id: 3, name: '에어팟 프로', price: '359,000원', desc: '노이즈 캔슬링 이어폰' },
  ]

  function ProductDetail() {
    const { id } = useParams()
    const navigate = useNavigate()

    // URL의 id는 문자열 -> 숫자로 변환해서 비교
    const porduct = productList.find((p) => p.id === Number(id))

    if (!product) {
      return <h1>존재하지 않는 상품입니다.</h1>
    }

    return (
      <div>
        <button onClick={() => navigate(-1)}><-뒤로가기</button>
        <h1>{product.name}</h1>
        <p>가격: {product.price}</p>
        <p>설명: {product.desc}</p>
      </div>
    )
  }

  export default ProductDetail
  ```
</details>

<details>
  <summary>(4) 흔한 실수</summary>

  ```JSX
  // X 실수: useParams 값을 그대로 숫자와 비교
  const product = productList.find((p) => p.id === id)
  // id는 문자열 "1", p.id는 숫자 1 -> === 비교에서 false

  // O 해결: Number()로 변환
  const product = productList.find((p) => p.id === Number(id))
  ```
