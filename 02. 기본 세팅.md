# 1. React Router 설정
<details>
  <summary>(1) BrowserRouter로 앱 감싸기</summary>

  * React Router를 사용하려면 **앱 전체를 `<BrowserRouter>`로 감싸야 함**
  * `main.jsx` 또는 `index.jsx`에서 설정
  * 감싸지 않으면 React Router의 모든 기능이 동작하지 않음
    ```JSX
    // main.jsx
    import { StrictMode } from 'react'
    import { createRoot } from 'react-dom/client'
    import { BrowserRouter } from 'react-router-dom'  // 추가
    import App from './App.jsx'

    createRoot(document.getElementById('root)).render(
      <StrictMode>
        <BrowserRouter>
          <App />
        </BrowserRouter>
      </StrictMode>
    )
    ```
</details>

<details>
  <summary>(2) BrowserRouter가 하는 일</summary>

  ```
  BrowserRouter
  ↓
  브라우저의 URL을 감지
  ↓
  URL 변경을 React에 알림
  ↓
  해당 URL에 맞는 컴포넌트를 렌더링
  ```
  * BrowserRouter는 눈에 보이는 UI를 만들지 않고, 뒤에서 URL을 감시하는 '감시자' 역할만 함
</details>

<details>
  <summary>(3) 프로젝트 폴더 구조 세팅</summary>

  ```
  src/
  ├── pages/
  │   ├── Home.jsx       ← 홈 페이지
  │   ├── About.jsx      ← 소개 페이지
  │   └── Contact.jsx    ← 연락처 페이지
  ├── App.jsx            ← 라우팅 설정
  └── main.jsx           ← BrowserRouter 설정
  ```
  ```JSX
  // pages/Home.jsx
  function Home() {
    return <h1>홈 페이지입니다</h1>
  }
  export default Home

  // pages/About.jsx
  function About() {
    return <h1>소개 페이지입니다</h2>
  }
  export default About

  // pages/Contact.jsx
  function Contact() {
    return <h1>연락처 페이지입니다</h1>
  }
  export default Contact
  ```
</details>

# 2. Routes와 Route - 페이지 나누는 기본 구조
<details>
  <summary>(1) Routes와 Route란?</summary>

  ```
  Routes  → Route들을 감싸는 그룹 (여러 경로를 묶음)
  Route   → URL 경로(path)와 컴포넌트(element)를 1:1로 연결
  ```
  * 비유: Routes는 '목차', Route는 '목차의 각 항목'
</details>

<details>
  <summary>(2) 기본 사용법</summary>

  ```JSX
  // App.jsx
  import { Routes, Route } from 'react-router-dom'
  import Home from './pages/Home'
  import About from './pages/About'
  import Contact from './pages/Contact'

  function App() {
    return (
      <Routes>
        <Route path="/"  element={<Home />} />
        <Route path="/about"  element={<About />} />
        <Route path="/contact"  element={<Contact />} />
      </Routes>
    )
  }

  export default App
  ```
</details>

<details>
  <summary>(3) 동작 원리</summary>

  ```
  사용자가 /about 주소로 이동
  ↓
  Routes가 모든 Route를 순서대로 확인
  ↓
  path="/about" 과 일치하는 Route 발견
  ↓
  element={<About />} 컴포넌트를 화면에 렌더링
  ```
</details>

<details>
  <summary>(4) path 작성 규칙</summary>

  ```JSX
  // 정확한 경로 (exact match)
  <Route path="/"  element={<Home />} />   // 주소가 정확히 / 일 때
  <Route path="/about" element={<About />} /> // 주소가 정확히 /about 일 때

  // 동적 경로(나중에 배울 내용 미리 보기)
  <Route path="/post/:id" element={<Post />} /> // /post/1, /post/2, /post/abc ...
  ```
</details>
